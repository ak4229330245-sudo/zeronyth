バリデーター申請

バリデーターは 24 時間動くサーバーでブロックを作ります。追加は既存バリデーターの投票（過半数）で決まります。
Validator application. Validators are added by a majority vote of existing validators.

流れ / Steps

  1. フルノードを動かして同期する（launch/public/fullnode-join.md の手順）。
  2. ノードの enode を確認：curl -s -X POST --data '{"jsonrpc":"2.0","id":1,"method":"admin_nodeInfo","params":[]}' http://127.0.0.1:8545 の enode（または besu public-key export）。
  3. 下のフォームに入力 →「申請データを作る」→ JSON をダウンロードして、公式の連絡先に送る。
  4. 運営が接続・同期・稼働を確認し、既存バリデーターが投票します。追加されると、あなたのノードがブロックを作り始めます。

秘密鍵・ノードキー（key ファイル）は絶対に送らないでください。申請に必要なのは公開情報（enode）だけです。enode からバリデーターアドレスが自動で計算されます。
Never send your node key. Only the public enode is needed; the validator address is derived from it.
