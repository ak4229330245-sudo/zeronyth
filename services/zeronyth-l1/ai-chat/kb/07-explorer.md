# ブロックエクスプローラ（ZERONYTH Scan）
ZERONYTH のブロックエクスプローラは https://scan.zeronyth.dpdns.org/ です（Etherscan のような専用サイト、読み取り専用）。トップの検索欄にアドレス・トランザクションハッシュ・ブロック番号・トークン名（例: zUSDC）を入れると開けます。日本語と英語を切り替えられ、スマホでも見られます。

# 自分のウォレットや取引を見る
https://scan.zeronyth.dpdns.org/address/<あなたのアドレス> を開くと、ZNYT 残高、送受信したすべてのトランザクション（ページ送りあり）、トークン残高とトークン送金、wZNYT やブリッジの記録、ポイントページへのリンクが見られます。トランザクションは /tx/<ハッシュ>、ブロックは /block/<番号>、トークンは /token/<コントラクト> で、状態・送信元・宛先・金額・手数料・ガス・関数名やイベントの解読まで表示します。表示されるのはチェーン上の公開データだけです。秘密鍵やシードフレーズは絶対に入力しないでください（エクスプローラは聞きません）。

# ウォレットに登録するエクスプローラ URL
MetaMask や OKX Wallet にネットワークを追加するときのブロックエクスプローラ URL は https://scan.zeronyth.dpdns.org です。サイトの「ウォレットに追加」ボタンもこの URL を登録します。以前の https://zeronyth.dpdns.org/tx/... や /address/... のリンクも自動で scan に転送されます。

# エクスプローラで見られるその他の情報
最新ブロックと最新トランザクション（自動更新）、ブロック高・平均ブロック時間・TPS・ガス価格・総供給量・バーン量、バリデータ一覧と各ブロックの提案者、トークン一覧と保有者ランキング、ブリッジの送金記録（相手チェーンのエクスプローラへのリンク付き）。ZnytEconomy・EmissionPool・FeeSplitter・RewardPool・ブリッジ・AMM・z トークン・wZNYT などの既知コントラクトには名前ラベルが付きます。内部トランザクション（コントラクト内部の ZNYT 移動）はノードにトレース機能がないため表示しません。
