# Native Token Economy (Simulation)

## Rules
- Using AI or VPS requires payment in the project's native testnet token (ZNYT).
- Node providers receive rewards in ZNYT for AI usage (and VPS contribution).
- All values are simulated. No real value. Testnet only.
- No mainnet assets. No real transfers.

## UI
- Node page shows usage cost and provider reward.
- Buttons simulate AI / VPS usage and update the numbers.
