# Gas Fee Partial Burn (Simulation)

## Mechanism
- AI usage fee: 60% to node providers, 20% burned, remainder retained
- VPS usage fee: 50% to node providers, 25% burned, remainder retained
- Burned amount is tracked and displayed
- Permanent reduction of circulating supply (simulation only)

## Constraints
- Testnet / local simulation only
- No real value
- No mainnet assets
- Quantum resistance and privacy unchanged
