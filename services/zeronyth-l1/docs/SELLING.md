# Marketplace Packaging Notes

Recommended title: **ZERONYTH L1 Developer Kit — Besu QBFT Private EVM Devnet + Security Modules**

Accurate claims:

- one-command four-validator QBFT local devnet
- Hyperledger Besu 26.9.0 execution client
- EVM JSON-RPC + MetaMask-compatible custom-network onboarding
- generated validator identities and deterministic static peering
- localhost-bound RPC and explorer
- internal development faucet with cooldown and chain-ID checks
- buyer-supplied optional prefunded address
- lightweight local block/validator dashboard
- sample guardian-recovery, commit/reveal, and commitment contracts
- optional ML-DSA-65 off-chain adapter boundary with no silent classical fallback
- clean release packaging with generated secrets excluded
- GitHub Actions full-stack E2E workflow for four-validator boot, consensus, explorer, faucet transfer, and release checks
- pinned Solidity 0.8.24 compilation in CI

Do **not** claim:

- audited or formally verified
- production-ready mainnet
- quantum-safe EVM transactions
- anonymous/private transactions
- complete MEV resistance
- a production-grade block explorer

Before listing, obtain a green **ZERONYTH Full E2E** GitHub Actions run for the exact commit/tag being sold. If you
also support a specific desktop OS, test that launcher on that OS before claiming desktop compatibility. Capture screenshots
from a real successful run and disclose the prerequisites and unaudited status in the product description.

Safe claim after a green workflow: **"Automated GitHub Actions E2E verified for this release."**
Do not convert that into claims such as audited, formally verified, production-safe, or guaranteed secure.

Use the ZIP generated by `make package`; do not sell a working directory containing `.env`, `networkFiles/`, generated
validator keys, or generated genesis files.
